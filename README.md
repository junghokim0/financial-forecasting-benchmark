# financial-forecasting-benchmark
Research project on foundation models for financial forecasting.

# Financial Foundation Model Benchmark

## Goal

Compare time-series foundation models (Chronos, TimesFM) with traditional forecasting models and Cryptova.

## Research Questions

1. Can foundation models outperform traditional time-series models?
2. Can foundation models outperform Cryptova?
3. In which market regimes does each model perform best?

## Models

- LSTM
- TimesNet
- Chronos
- TimesFM
- Cryptova
